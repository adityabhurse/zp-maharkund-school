# Foto Directory (Web Static Images)

Put any photos you want to use directly on the web app in this folder or in the root `foto/` folder.

- **Web Access Path:** `/foto/your-photo-name.jpg`
- **Example Usage in Code / Pages:** `<img src="/foto/event1.jpg" alt="Event" />`
- **Admin Access:** These files are **NOT accessible, editable, or manageable via the Admin Portal UI** (`/admin`). They are static assets managed manually on disk.
