# Root Foto Directory

Place any photos here that are needed for the web app and should **not** be accessible or manageable by the admin panel.

- **Web URL Path:** `/foto/filename.ext` (e.g. `/foto/banner.jpg`)
- **Admin Panel Protection:** This directory is strictly isolated from the staff/admin panel API (`/api/gallery`). Admin users cannot view, modify, or delete files stored here through the admin UI.
